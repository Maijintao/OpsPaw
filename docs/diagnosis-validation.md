# 诊断迁移检查范围

当前分支接入平台管理、监控、诊断采集、定位、归因与回放。修复、告警、事故和 RAG 不在本批范围。

检查包括独立 SQLite 中的平台管理、诊断发起与存档、对话卡片、工单确认，以及已有采集、统计、定位、调用边、变更、日志、归因适配与 HTTP 回放检查。OpsAgent 实际依赖导入使用本机已有的完整项目 Python 环境，项目依赖已登记并更新锁文件，未在本次重复下载全部模型运行包。

离线样例评分仅覆盖确定性采集结果到候选与排序的部分，不能代表真实模型归因准确率或真实环境效果。本批没有进行故障注入、平台复位或线上部署。回放未命中及数据不足应明确显示，不能算作健康。

已有实现仍有待改进之处：模型失败时可能退回首选候选，自由文本到服务名的转换仍需谨慎看待。三角色实际各执行一次分析，未执行交叉评审。此次迁移不声称已解决这些问题。
